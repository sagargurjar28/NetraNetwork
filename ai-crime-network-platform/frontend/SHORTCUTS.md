# Shortcuts (verified)

| Shortcut | Action | Notes |
|----------|--------|-------|
| Cmd/Ctrl+K | Toggle copilot drawer | Global, implemented in AppShell; also works from copilot input |
| Esc | Close modal or drawer | Global: closes copilot drawer, SourceDrawer, Modal, graph menu |
| Enter | Send copilot message | Copilot input focused, disabled while streaming |
| Shift+Enter | Newline | Copilot textarea, auto-grow up to 6 lines |
| Tab/Shift+Tab | Move focus | All pages, visible red focus ring |

Graph: drag nodes, hover edges (toast), click select → right panel, right-click → Expand/Isolate/Hide/Pin.
